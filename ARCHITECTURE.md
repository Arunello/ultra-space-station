# Описание архитектуры проекта «Космическая станция»

- **Station** — класс-контейнер, хранящий коллекцию объектов `Module` и ограничивающий их максимальное количество. Предоставляет методы для добавления, удаления и поиска модулей по индексу или ID. Реализует интерфейс `Iterable<Module>` для перебора модулей.

- **Module** — абстрактный базовый класс, содержащий общие поля модулей: ID, название, эффективность, состояние и характеристики. От него наследуются три категории: `ResidentialModule`, `EnergyModule` и `ResearchModule`, каждая из которых включает конкретные типы модулей.

- **Durability, EnergyConsumption и Capacity** — классы, хранящие характеристики модулей: прочность, энергопотребление и вместимость. Каждый класс предоставляет методы для получения и изменения значения с проверкой допустимых значений.

- **ModuleFactory** — интерфейс, определяющий методы создания модулей разных категорий. `StandardModuleFactory` и `AdvancedModuleFactory` реализуют фабрики стандартных и улучшенных модулей.

- **StationIterator** — вложенный класс `Station`, реализующий интерфейс `Iterator<Module>` и обеспечивающий последовательный перебор модулей станции.

## Связи между классами

`Station` содержит коллекцию объектов `Module`. Каждый модуль использует объекты `Durability`, `EnergyConsumption` и `Capacity` для хранения своих характеристик. Конкретные модули наследуются от соответствующих категорий. Фабрики создают модули, а `StationIterator` обеспечивает их перебор.
